yt-factory Privacy Policy

Last updated: October 29, 2026

Who uses this app

yt-factory is a personal tool used only by its owner, on the owner's own Google account and YouTube channel. It is not offered to the public and does not collect data from any other person.

What the app accesses

With the owner's explicit consent through Google OAuth, the app uses:

  • YouTube upload (youtube.upload): to upload videos to the owner's channel.
  • YouTube read-only (youtube.readonly): to read view, like and comment counts of the owner's own videos, and public trending lists, so the tool can choose better future topics.

How data is stored and shared

The OAuth refresh token is stored only in the owner's local environment and in the owner's private code repository secrets. Video statistics are stored in a small file in that private repository. No data is sold, shared, transferred to third parties, or used for advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
